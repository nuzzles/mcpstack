# mcpstack

A Rust CLI for humans and agents to install multiple MCP servers, version-control
and switch stacks, and share setups across teams.

## Harness Support

| --- | --- |
| Codex | ✅ |
| Claude Code | ✅ |
| Claude Desktop | ❌ |
| Cursor | ❌ |
| Gemini CLI | ❌ |
| OpenCode | ❌ |
| VS Code/Copilot | ❌ |
| Windsurf | ❌ |

✅ Supported · 🚧 In progress · ❌ Not implemented
