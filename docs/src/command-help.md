# mcpstack help

Show help for mcpstack or a command without reading or changing client configuration.

```sh
mcpstack help
mcpstack help codex
mcpstack help codex import
mcpstack help claude use
mcpstack help validate
```

You can also append `--help` to any command, such as `mcpstack codex import --help`.
`-h` prints a shorter summary where a command has extended option descriptions.

For the executable version, run `mcpstack --version`. For structured discovery,
run `mcpstack --schema`. See [global options and exit codes](cli-reference.md).
