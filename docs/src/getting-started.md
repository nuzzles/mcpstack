# Installation

Requires [Rust 1.98+](https://www.rust-lang.org/tools/install).

Install [from source](install-source.md) or through [Crates.io](install-crates.md).
Keep Cargo's binary directory on your `PATH`, then check your version:

```sh
mcpstack --version
```

These docs cover **0.1.0**. Next: [try a stack](workflows.md#try-it).
