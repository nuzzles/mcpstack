# mcpstack

Manage, share, and switch MCP server configurations across **Codex** and **Claude Code**.

```sh
mcpstack codex export work.yaml --non-interactive
mcpstack claude diff work.yaml
mcpstack claude import work.yaml
```

Version **0.1.0**. Manages configuration; does not install or run servers.
