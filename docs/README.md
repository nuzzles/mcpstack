# Documentation site

[Site](https://nuzzles.github.io/mcpstack/) · mdBook **0.5.4** · Python **3.11+**

## Build

Install [mdBook 0.5.4](https://github.com/rust-lang/mdBook/releases/tag/v0.5.4)
and the Rust toolchain required by `Cargo.toml`.

```sh
python3 docs/build.py
python3 -m http.server 8000 --directory target/docs-site
```

Open <http://localhost:8000/>. Optional: `--mdbook <PATH>`, `--binary <PATH>`.

## Edit

- Pages and navigation: `docs/src/`.
- Short command guides: `docs/command-guides/`.
- Compatibility table: imported from the root README's Harness Support section.
- Command pages, downloadable help, CLI schema, and agent files: generated by `docs/build.py`.

Keep prose short and examples synthetic. Release versions come from the CLI schema
(derived from `Cargo.toml`); do not hardcode them in page content.
The build checks YAML examples, scratch workflows, links, and anchors. Output lives
in `target/docs-site`; do not commit it.

## Publish

PRs build only. Main deploys through GitHub Pages. For a fork, enable Pages with
GitHub Actions and update repository URLs in `docs/book.toml` and `docs/build.py`.
Upgrade mdBook's version and workflow checksum together.
